# YottaGen Limitations & Future Roadmap

To uphold the highest quality and honesty bar, this document transparently enumerates the current system boundaries, constraints, and planned architectural enhancements.

---

## 1. Current System Limitations

1. **Synthetic Provenance & Absence of Real External Data**:
   - As mandated by the problem specification, all data generated by YottaGen is 100% synthetic. No real personal records, banking networks, or corporate databases were ingested or queried.
   - All corporate email addresses terminate in `@example.com` per RFC 2606.
2. **Static Fixed Foreign Exchange Rates**:
   - Multi-currency conversions to base USD rely on fixed rates defined in `config.py` (`USD=1.0000`, `EUR=1.0800`, `GBP=1.2800`, `SGD=0.7400`, `INR=0.0120`).
   - Real-world enterprise ERPs query daily floating spot rates from FX providers (e.g., Bloomberg, OANDA). Daily FX volatility is not modeled in this release.
3. **Receipt Files are Metadata-Only**:
   - Receipts are modeled as embedded metadata objects (`receipt_id`, SHA-256 cryptographic hash, vendor name, receipt date, file name) rather than binary PDF or OCR image files on disk.
4. **Scope of Statutory Holiday Calendars**:
   - The statutory holiday calendar models the 5 primary specified jurisdictions: India (`IN`), United States (`US`), United Kingdom (`UK`), Germany (`DE`), and Singapore (`SG`).
   - Regional / state-level holidays (e.g., Bavaria-specific holidays in Germany or Karnataka-specific holidays in India) are simplified to national statutory holidays.
5. **Single Hierarchy Root**:
   - The organizational hierarchy assumes a single company tree headed by one Chief Executive Officer. Holding companies with multiple independent legal entities or dotted-line matrix reporting are not modeled.

## 2. Production Enhancements & Roadmap

1. **Streaming Anomaly Detection via Apache Kafka / Flink**:
   - Convert the batch audit engine in `audit.py` into a streaming CEP (Complex Event Processing) pipeline to evaluate transactions in real-time as events arrive.
2. **Machine Learning Anomaly Detection**:
   - Train an isolation forest or graph neural network on employee submission patterns to identify subtle collusive fraud rings and anomalous claim sequences.
3. **Dynamic Currency Rate Tables**:
   - Introduce an `ExchangeRateDaily` table tracking daily FX fluctuations with interpolation for weekend expenditures.
4. **Multi-Entity Matrix Reporting**:
   - Support dotted-line functional managers and regional compliance officers on multi-country cross-border assignments.
